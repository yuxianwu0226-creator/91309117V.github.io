學期學習心得 這學期的課程主要是學習 GitHub 與版本控制，對我來說是一個全新的領域。一開始，我對GitHub 的概念並不熟悉，只知道它們和程式碼有關，但不清楚實際用途。透過課程學習，我漸漸理解了版本控制的重要性，以及它在軟體開發或專案合作中的實際應用。 課程開始時，我學會了 Git 的基本指令，這些指令讓我能夠把自己的程式碼版本清楚記錄下來，並在需要時回到過去的版本。剛開始使用時會有點混亂，特別是對於分支（branch）和合併（merge）的概念不太熟悉，但透過反覆練習，我逐漸掌握了如何在不同分支上開發功能，並安全地合併回主要分支。 除了個人操作，課程也讓我們實際體驗團隊協作。我學會了如何透過 GitHub 協作專案。這讓我體會到版本控制不只是技術，更是一種有效的專案管理方式，可以讓多人合作時避免衝突，並保持程式碼的完整性與可追蹤性。 此外，我也學到了如何利用 GitHub Pages 將專案部署到網路上，讓作品可以被他人直接瀏覽，這種實際的成就感讓我更有動力學習。 總結這一學期的學習，我不僅掌握了 Git 與 GitHub 的操作技巧，也理解了團隊協作和版本管理的重要性。這對我未來在程式開發、專案合作甚至個人專案管理都有很大幫助。我也期待在未來能進一步學習更多進階功能，如 Git 的衝突處理、工作流程（workflow）自動化，以及與其他工具整合，讓我的程式開發能力更全面。
